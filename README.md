> 名字化用自古典语词的「杂记本」，此处按个人习惯拼作 `zibaidone`。

- 站点：<https://zava1on.github.io/>
- 课程指南：<https://zava1on.github.io/tgbook/>
- 历年试题索引：<https://zava1on.github.io/tgbook/exams/>
- 资料仓库（试题 PDF）：<https://github.com/Zava1on/TrivialGroup>

## 目录

| 位置 | 内容 |
| :--- | :--- |
| [`notes/math/`](notes/math/) | 数学讲义与笔记（讲义为 PDF，短记用 Markdown） |
| [`notes/reading/`](notes/reading/) | 读书摘记与书评 |
| [`notes/misc/`](notes/misc/) | 杂记、零散想法 |
| [`templates/note.md`](templates/note.md) | 单篇笔记模板 |

## 约定

- **讲义**：编译好的 PDF 放在 `notes/math/`，命名 `Zavalon-<课程代号>-notes.pdf`（代号与课程指南一致）。
- **短记**：Markdown，文件名用小写英文或课程代号（如 `ra.md`、`pde.md`），便于排序与检索。
- 每篇 Markdown 首行写 `# 标题`，其后用模板里的元信息块（日期 / 标签 / 参考）。
- 数学公式用 LaTeX：行内 `$...$`，行间 `\[ ... \]`。
- 标点与术语尽量统一；引用他人资料时在「参考」里给出出处。
